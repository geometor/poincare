Exact Symbolic Poincaré Conformal Hyperbolic Disk Demonstrations (SymPy + geometor.model)

In strict accordance with GEOMETOR’s Content / Code Separation, executable Python constructions live outside the historical :layout: book pages of La Science et l’Hypothèse and operate in geometor.poincare.disk and demos/ with zero ``float`` or ``sp.Float`` coordinates.

Because Poincaré’s conformal dictionary represents the hyperbolic plane inside the Euclidean unit disk $\mathbb{D} = \{(x, y) : x^2 + y^2 < 1\}$ bounded by the ideal horizon $\Omega: x^2 + y^2 = 1$, every hyperbolic geodesic is either a Euclidean diameter through $O(0,0)$ or a Euclidean circle cutting $\Omega$ orthogonally ($|OC|^2 - r^2 = 1$). Straightedge-and-compass constructions in geometor.model therefore execute 100% exact hyperbolic geometry over $\mathbb{Q}$ and quadratic radical extensions.

1. Horizon Inversion, Orthogonal Geodesic Circles & Rational Quadrances¶

         48def _klein_hilbert_quadrance(
         49    k1: sp.geometry.Point2D,
         50    k2: sp.geometry.Point2D,
         51) -> sp.Expr:
         52    r"""Compute the Beltrami–Klein metric invariant directly from Klein coordinates.
         53
         54    For interior Klein points :math:`K_1, K_2`, the Cayley–Klein quadrance satisfies
         55    :math:`1 - q_{\text{CK}}(K_1, K_2) = \frac{(1 - \|K_1\|^2)(1 - \|K_2\|^2)}{(1 - K_1 \cdot K_2)^2}`.
         56    """
         57    n1 = k1.x**2 + k1.y**2
         58    n2 = k2.x**2 + k2.y**2
         59    dot = k1.x * k2.x + k1.y * k2.y
         60    return sp.simplify(1 - ((1 - n1) * (1 - n2)) / (1 - dot) ** 2)

         72        for el in m:
         73            if el.has(sp.Float):
         74                raise AssertionError(f"Floating-point atom detected in {el!r}")
         75
         76    p1, p2 = bridge.poincare_points
         77    k1, k2 = bridge.klein_points
         78    poincare_metrics = hyperbolic_cross_ratio_and_quadrance(
         79        p1, p2, bridge.poincare_geodesic.U, bridge.poincare_geodesic.V
         80    )
         81    q_ck_from_klein = _klein_hilbert_quadrance(k1, k2)
         82    assert zero_test(poincare_metrics.cayley_klein_quadrance - q_ck_from_klein)
         83
         84    if svg_dir is not None:
         85        svg_dir.mkdir(parents=True, exist_ok=True)
         86        for fname in (
         87            "fig6_heated_disk_refraction.svg",
         88            "fig7_cayley_klein_beltrami_bridge.svg",
         89            "fig8_stellar_parallax_conventionalism.svg",
         90        ):
         91            (svg_dir / fname).write_text(render_figure_svg(fname), encoding="utf-8")
         92
         93    return heated, bridge, parallax
