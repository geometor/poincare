class geometor.poincare.HyperbolicMetricReport¶

Exact cross-ratio and Rational Hyperbolic Quadrance invariants for \(P, Q \in \mathbb{D}\).

Unites Poincaré’s cross-ratio logarithmic distance with Norman Wildberger’s transcendental-free Universal Hyperbolic Geometry (UHG) and Cayley–Klein quadrances:

  • cross_ratio: \(\chi(P, Q; U, V) = \frac{|PV|\cdot|QU|}{|PU|\cdot|QV|} \ge 1\)

  • cross_ratio_squared: \(\chi^2(P, Q; U, V) = \frac{Q(P,V)\,Q(Q,U)}{Q(P,U)\,Q(Q,V)}\)

  • poincare_distance: \(d_{\mathbb{H}}(P, Q) = \ln \chi(P, Q; U, V)\)

  • conformal_quadrance: \(\tau(P, Q) = \frac{\|P-Q\|^2}{\|1 - \bar{P}Q\|^2} = \left(\frac{\chi-1}{\chi+1}\right)^2 \in [0, 1)\)

  • wildberger_uhg_quadrance: \(q_{\text{UHG}}(P, Q) = -\frac{4\tau}{(1-\tau)^2} = -\sinh^2 d_{\mathbb{H}}(P, Q) \in \mathbb{Q}(P, Q)\)

  • cayley_klein_quadrance: \(q_{\text{CK}}(P, Q) = \frac{4\tau}{(1+\tau)^2} = \tanh^2 d_{\mathbb{H}}(P, Q) \in [0, 1)\)

  • isometric_delta: \(\delta(P, Q) = \frac{2\|P-Q\|^2}{(1-\|P\|^2)(1-\|Q\|^2)} = \cosh d_{\mathbb{H}}(P, Q) - 1\)

geometor.poincare.construct_hyperbolic_geodesic(model: geometor.model.Model, P: sympy.geometry.Point2D, Q: sympy.geometry.Point2D, *, classes: list[str] | None = None, label: str | None = None) → HyperbolicGeodesic¶

Construct the unique hyperbolic geodesic through \(P, Q \in \overline{\mathbb{D}}\).

Implements Poincaré’s Translation Dictionary (La Science et l’Hypothèse, Ch. III):

  • When \(O, P, Q\) are collinear, constructs the Euclidean diameter line \(PQ\) and intersects it with \(\Omega\) to obtain antipodal ideal points \(U, V\).

  • When \(O, P, Q\) are non-collinear and at least one point lies strictly inside \(\mathbb{D}\), constructs its horizon inverse \(P^* = P / \|P\|^2\) and circumscribes the unique Euclidean circle through \((P, Q, P^*)\). By power-of-a-point (\(|OP|\cdot|OP^*| = 1 = R_\Omega^2\)), this circle cuts \(\Omega\) orthogonally at two exact ideal points \(U, V \in \partial\Omega\).

  • When both \(P\) and \(Q\) lie on \(\partial\Omega\) (ideal geodesic), intersects the Euclidean horizon tangents at \(P\) and \(Q\) to locate the exact orthogonal circle center \(C\).

Parameters:

  • model – Active geometor.model.Model.

  • P – First point in \(\overline{\mathbb{D}}\).

  • Q – Second distinct point in \(\overline{\mathbb{D}}\).

  • classes – Optional CSS/semantic class tags for the constructed geodesic element.

  • label – Optional identifier for the constructed geodesic element.

Returns:

Populated HyperbolicGeodesic dataclass (unpackable as (carrier, U, V)).

Raises:

  • TypeError – If P or Q contains floating-point coordinates.

  • ValueError – If P == Q or either point lies outside \(\overline{\mathbb{D}}\).

Construct the exact rational ideal hyperbolic triangle on \(U_1, U_2, U_3 \in \partial\Omega\).

Uses Pythagorean horizon points \(U_1 = (1, 0)\), \(U_2 = (-\frac{3}{5}, \frac{4}{5})\), and \(U_3 = (-\frac{3}{5}, -\frac{4}{5})\). Every side is an orthogonal Euclidean circle with 100% rational center and rational radius:

  • \(C_{12} = (1, 2),\; r_{12} = 2\)

  • \(C_{13} = (1, -2),\; r_{13} = 2\)

  • \(C_{23} = (-\frac{5}{3}, 0),\; r_{23} = \frac{4}{3}\)

Meeting tangentially along radii \(OU_1, OU_2, OU_3\) with interior spreads (0, 0, 0) (\(0^\circ\) angle sum, maximal Gauss–Bonnet defect \(\pi\)).

Parameters:

model – Optional geometor.model.Model (created if None).

Verified IdealTriangleResult.

geometor.poincare.construct_inversion_in_horizon(model: geometor.model.Model, P: sympy.geometry.Point2D, *, label: str | None = None) → sympy.geometry.Point2D¶

Construct the exact Euclidean inverse \(P^* = P / \|P\|^2\) in \(\Omega: x^2+y^2=1\).

Uses pure straightedge-and-compass geometry inside model:

  • If \(P \in \partial\Omega\) (\(\|P\|^2 = 1\)), returns \(P\) itself.

  • If \(0 < \|P\|^2 < 1\) (\(P \in \mathbb{D} \setminus \{O\}\)), erects the chord perpendicular to \(OP\) at \(P\) meeting \(\Omega\) at \(T_1\), then intersects the horizon tangent at \(T_1\) with ray \(OP\) (Euclid VI.8: \(|OP|\cdot|OP^*| = |OT_1|^2 = 1\)).

  • If \(\|P\|^2 > 1\), constructs the Thales circle on diameter \(OP\) meeting \(\Omega\) at \(T_1, T_2\) and intersects polar chord \(T_1 T_2\) with \(OP\).

Parameters:

  • model – Active geometor.model.Model.

  • P – Exact non-origin point spg.Point2D.

  • label – Optional label for the constructed inverse point P*.

Returns:

Exact inverse point \(P^*\) satisfying \(Q(O, P) \cdot Q(O, P^*) = 1\).

Raises:

  • TypeError – If P contains floating-point coordinates.

  • ValueError – If P coincides with the horizon center O = (0, 0).

Construct two limiting horoparallels and two ultraparallels to L_hyp through P.

Demonstrates inside geometor.model that Euclid’s Fifth Postulate fails in the Poincaré disk while Postulates I–IV (in Poincaré’s dictionary) hold identically: through a single point \(P \notin L_{\text{hyp}}\), infinitely many hyperbolic lines fail to meet \(L_{\text{hyp}}\).

  • P – Exterior point in \(\mathbb{D} \setminus L_{\text{hyp}}\). Defaults to \((\frac{1}{6}, \frac{2}{5})\).

Returns:

Verified UltraparallelPencil with exact disjointness over \(\overline{\mathbb{D}}\).

Compute the exact algebraic cross-ratio and Wildberger’s Rational Hyperbolic Quadrance.

Eliminates transcendental logarithms for algebraic comparison while verifying the exact polynomial bridge \((1 - \tau)^2 (\chi^2 + 1)^2 = 4 (1 + \tau)^2 \chi^2\) between the 4-point circle chord cross-ratio \(\chi(P, Q; U, V)\) and the purely rational conformal/UHG quadrances over \(\mathbb{Q}\).

  • U – First ideal endpoint on \(\partial\Omega\) (constructed automatically if None).

  • V – Second ideal endpoint on \(\partial\Omega\) (constructed automatically if None).

Returns:

Populated HyperbolicMetricReport with 100% exact SymPy invariants.

Raises:

  • TypeError – If any point contains sp.Float coordinates.

  • ValueError – If P or Q does not lie strictly inside \(\mathbb{D}\).
