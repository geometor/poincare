geometor.poincare.render¶

Publication-grade interactive .euclid-graphic SVG renderer for geometor.poincare.

Generates theme-adaptive SVGs directly from exact geometor.poincare.disk symbolic constructions while preserving canonical data-ref attributes, <defs> midpoint tick markers (#geom-tick-1..3), 3-vertex midpoint <path> arcs and segments, and #highlights overlay groups consumed by PHOTON Publish’s geometor_interactive.js and .. picture:: directive.
