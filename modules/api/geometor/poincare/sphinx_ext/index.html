geometor.poincare.sphinx_ext¶

Runtime Sphinx & photon-platform/publish integration for GEOMETOR Poincaré.

Registers the fr (“French (1902)”) companion track in photon_platform.publish.book at build time (without modifying photon-platform/publish) and configures offline-safe local intersphinx inventories across the GEOMETOR ecosystem.
