geometor.poincare.concordance¶

Scholarly concordance, archival witness verification, and RST apparatus compiler.

Manages the JSON registries in resources/science_and_hypothesis/ (mirrored to resources/ for PHOTON Publish hover-card resolution), verifies SHA-256 digests of the public-domain 1902 French and 1905 English primary witnesses, checks 4-track Book Codex synchronization, and compiles concordance.rst, bibliography.rst, persons.rst, and glossary.rst.
